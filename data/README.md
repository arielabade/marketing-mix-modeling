# Data

Generated by `src/mmm/simulate.py`; not committed.

## This dataset is SIMULATED, and that is the point

A marketing mix model estimates how much revenue each channel caused. On real data that quantity is
never observed, so an MMM's output can be inspected but not **scored**: there is nothing to compare it
against.

Simulating from a process whose parameters are written down in `src/mmm/config.py` is the only way to
ask "does this model recover the truth?" and answer it with a number.

The model is given exactly what a client's data team can hand over — dates, weekly spend per channel,
weekly revenue. It is never shown the adstock rates, the saturation curves, the baseline or the
per-channel contributions, all of which the config file knows.

No real company's spend or revenue appears anywhere in this repository.
